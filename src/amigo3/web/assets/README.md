# Local visual assets

- `go-logo.png`: GO icon from the Gene Ontology Consortium's AmiGO repository,
  https://github.com/geneontology/amigo/blob/master/static/images/go-logo-icon.small.png.
  Used as the link to the Gene Ontology website. The GO mark belongs to its owners.
- Lato 400/700 and Raleway 600: served locally, obtained from Google Fonts on
  2026-10-10. Each font's SIL Open Font License is included in `fonts/`.
  Sources: https://github.com/google/fonts/tree/main/ofl/lato and
  https://github.com/google/fonts/tree/main/ofl/raleway.

The browser makes no external requests for styles, fonts or scripts.
